Preview:
1. Extract this ZIP.
2. Open the folder in Visual Studio Code.
3. Open index.html in your browser, or use Live Server.

Publish on Render:
- Upload the files and assets to the root of a GitHub repository.
- In Render, create a Static Site connected to that repository.
- Leave Build Command blank and set Publish Directory to ".".
